Olá! Eu sou **Sophia Melo**, estudante de **Análise e Desenvolvimento de Sistemas** e desenvolvedora com foco em **Backend**.

Minha jornada na tecnologia é construída principalmente através de projetos práticos, nos quais transformo conceitos de programação em sistemas funcionais e organizados.

Tenho desenvolvido aplicações utilizando **Java, SQL e MySQL**, trabalhando com conceitos como:

* Programação Orientada a Objetos
* CRUD e persistência de dados
* JDBC
* Hibernate
* Maven
* Modelagem UML
* MER / DER
* Arquitetura e organização de código
* Princípios SOLID
* Git e GitHub
* Java Swing e interfaces desktop
* Documentação técnica

Mais do que apenas escrever código, busco compreender **por que uma solução funciona, como ela pode ser estruturada e como pode evoluir**.
